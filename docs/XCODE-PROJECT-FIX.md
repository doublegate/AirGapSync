# Fixing Corrupted Xcode Project for AirGapSync

## Problem Description

The Xcode project file (`AirGapSync.xcodeproj/project.pbxproj`) generated by the build script is corrupted and produces the following error when opened:

```
The project 'AirGapSync' is damaged and cannot be opened. Examine the project file for invalid edits or unresolved source control conflicts.

Path: /Users/parobek/Code/AirGapSync/AirGapSync.xcodeproj
Exception: -[PBXFileReference buildPhase]: unrecognized selector sent to instance 0x6000063cd1e0
```

## Root Cause

The `build-phase1.sh` script generated an invalid Xcode project structure with:
- Incorrect object reference IDs
- Missing build phase definitions
- Improperly linked file references
- Invalid PBXFileReference entries that point to non-existent build phases

## Solution: Create a New Xcode Project

Since the generated project file is fundamentally corrupted, the best solution is to create a fresh Xcode project and import the existing Swift source files.

### Step 1: Remove the Corrupted Project

```bash
cd /Users/parobek/Code/AirGapSync
rm -rf AirGapSync.xcodeproj
```

### Step 2: Create a New Xcode Project

1. Open Xcode
2. Choose **Create New Project** (or File → New → Project)
3. Select **macOS** → **App**
4. Click **Next**
5. Configure the project:
   - **Product Name**: `AirGapSync`
   - **Team**: Select your development team
   - **Organization Identifier**: `com.doublegate` (or your preferred identifier)
   - **Bundle Identifier**: Will auto-generate as `com.doublegate.AirGapSync`
   - **Interface**: SwiftUI
   - **Language**: Swift
   - **Use Core Data**: Unchecked
   - **Include Tests**: Checked
6. Click **Next**
7. Save location: `/Users/parobek/Code/AirGapSync`
8. Click **Create**

### Step 3: Remove Default Files

Delete these auto-generated files from the Xcode project (move to trash):
- `ContentView.swift`
- Any other default SwiftUI views

### Step 4: Import Existing Swift Files

1. In Xcode, right-click on the **AirGapSync** folder in the project navigator
2. Choose **Add Files to "AirGapSync"...**
3. Navigate to `/Users/parobek/Code/AirGapSync/src/swift_ui/`
4. Select all Swift files and folders
5. **Important**: Ensure these options are set:
   - **Copy items if needed**: UNCHECKED (files already exist)
   - **Create groups**: Selected
   - **Add to targets**: AirGapSync (checked)
6. Click **Add**

### Step 5: Organize Project Structure

Create logical groups in Xcode to organize the files:

1. Right-click on the AirGapSync folder → New Group → name it "Views"
2. Right-click on the AirGapSync folder → New Group → name it "Models"
3. Right-click on the AirGapSync folder → New Group → name it "Managers"
4. Drag files into appropriate groups:
   - **Views**: MainView.swift, HeaderView.swift, StatusView.swift, DevicesView.swift, SettingsView.swift, FooterView.swift
   - **Models**: Device.swift
   - **Managers**: SyncManager.swift
   - **Root**: AirGapSyncApp.swift

### Step 6: Configure Build Settings

1. Select the project in the navigator
2. Select the **AirGapSync** target
3. Go to **Build Settings** tab
4. Configure:
   - **Deployment Target**: macOS 10.15 or later
   - **Swift Language Version**: Swift 5
   
### Step 7: Add Entitlements (if needed)

For a menu bar app with keychain access:

1. Select the project → AirGapSync target → Signing & Capabilities
2. Click **+ Capability**
3. Add:
   - **Keychain Sharing** (for keychain access)
   - **Hardened Runtime** (for distribution)

### Step 8: Configure Info.plist for Menu Bar App

1. Select Info.plist
2. Add key: **Application is agent (UIElement)** = YES
   - This makes it a menu bar only app without dock icon

### Step 9: Test the Project

1. Select a build scheme (My Mac)
2. Press **Cmd+B** to build
3. Fix any compilation errors
4. Press **Cmd+R** to run

## Alternative: Use Makefile Build System

If you prefer not to use Xcode, the project includes a comprehensive Makefile:

```bash
# Build the Rust CLI tool
make build      # Debug build
make release    # Release build

# Run tests
make test

# Run the CLI
./target/debug/airgapsync --help
```

The SwiftUI app requires Xcode for building, but the core Rust functionality can be built and tested without it.

## Preventing Future Issues

To avoid this problem in the future:

1. Don't use automated scripts to generate Xcode projects
2. Create Xcode projects manually through the Xcode interface
3. Version control the `.xcodeproj` file after manual creation
4. Use `.gitignore` to exclude user-specific Xcode files:
   ```
   *.xcodeproj/xcuserdata/
   *.xcodeproj/project.xcworkspace/xcuserdata/
   ```
