## Overview

### What is the FFI?

The FFI (Foreign Function Interface) layer provides C-compatible functions that can be called from other languages. All Rust functionality is exposed through a stable C API.

### Header File

The C header is automatically generated from Rust code:

**Location**: `target/airgapsync.h` (auto-generated during build)

### Library Files

**Static Library**: `target/release/libairgap_sync.a`
**Dynamic Library**: `target/release/libairgap_sync.dylib`

### Building

```bash
# Build library
cargo build --lib --release

# Generate header
# (Automatically generated by build.rs)
ls target/airgapsync.h
```

## Getting Started

### Swift Integration

1. **Add Bridging Header**:

```objective-c
// AirGapSync-Bridging-Header.h
#import "airgapsync.h"
```

2. **Configure Build Settings**:
   - Library Search Paths: `$(SRCROOT)/target/release`
   - Header Search Paths: `$(SRCROOT)/target`
   - Other Linker Flags: `-lairgap_sync -lresolv`
   - Bridging Header: `$(SRCROOT)/AirGapSync-Bridging-Header.h`

3. **Use in Swift**:

```swift
// Initialize library
let result = airgap_initialize()
if result.error_code != Success {
    // Handle error
}
```

### C/C++ Integration

```c
#include "airgapsync.h"

int main() {
    // Initialize
    FFIResult result = airgap_initialize();
    if (result.error_code != Success) {
        fprintf(stderr, "Initialization failed\n");
        return 1;
    }

    // Use library functions...

    return 0;
}
```

Compile with:
```bash
gcc -o myapp main.c -L target/release -lairgap_sync -lresolv
```

## Types

### FFIErrorCode

Error codes returned by FFI functions:

```c
typedef enum FFIErrorCode {
    Success = 0,
    NullPointer = 1,
    InvalidUtf8 = 2,
    ConfigError = 3,
    CryptoError = 4,
    KeychainError = 5,
    IoError = 6,
    DeviceNotFound = 7,
    SyncError = 8,
    Unknown = 99
} FFIErrorCode;
```

### FFIResult

Standard result type for operations:

```c
typedef struct FFIResult {
    FFIErrorCode error_code;
    char* error_message;  // NULL if success, otherwise error description
} FFIResult;
```

**Memory**: You must free `error_message` with `airgap_free_string()`.

### FFISyncOptions

Configuration for sync operations:

```c
typedef struct FFISyncOptions {
    bool dry_run;                 // Preview mode, no actual changes
    bool verbose;                 // Enable verbose logging
    uint32_t parallel_workers;    // Number of concurrent processors
    uint64_t chunk_size;          // Chunk size in bytes
    bool verify_after_write;      // Verify data after writing
    bool resume;                  // Resume from previous sync
    uint32_t compression_level;   // 0-9, higher = more compression
    bool show_progress;           // Enable progress reporting
    uint32_t max_retries;         // Maximum retry attempts
} FFISyncOptions;
```

### FFISyncResult

Result of sync operation:

```c
typedef struct FFISyncResult {
    uint64_t files_synced;        // Number of files synced
    uint64_t bytes_transferred;   // Total bytes transferred
    uint64_t files_skipped;       // Files skipped (unchanged)
    uint64_t files_failed;        // Files that failed
    uint64_t duration_seconds;    // Total duration
    uint64_t average_transfer_rate; // Average bytes/sec
    char* snapshot_id;            // Created snapshot ID (can be NULL)
} FFISyncResult;
```

**Memory**: You must free `snapshot_id` with `airgap_free_string()`.

### FFIDeviceInfo

Information about a device:

```c
typedef struct FFIDeviceInfo {
    char* id;                     // Device ID
    char* name;                   // Device name
    char* mount_point;            // Mount point path
    bool is_encrypted;            // Whether device is encrypted
    uint64_t total_capacity;      // Total device capacity (bytes)
    uint64_t available_capacity;  // Available space (bytes)
    uint64_t last_sync_timestamp; // Last sync Unix timestamp
    uint32_t snapshot_count;      // Number of snapshots
} FFIDeviceInfo;
```

**Memory**: You must free with `airgap_free_device_info()`.

### Opaque Pointers

These types are opaque - you cannot access their contents directly:

- `Config*` - Configuration handle
- `SyncEngineHandle*` - Sync engine handle

## Functions

### Initialization

#### airgap_initialize

Initialize the AirGapSync library.

```c
FFIResult airgap_initialize(void);
```

**Returns**: FFIResult with success or error code.

**Note**: Must be called before any other FFI functions.

**Example**:
```c
FFIResult result = airgap_initialize();
if (result.error_code != Success) {
    fprintf(stderr, "Failed to initialize\n");
    exit(1);
}
```

#### airgap_get_version

Get the library version string.

```c
char* airgap_get_version(void);
```

**Returns**: Version string (must be freed with `airgap_free_string`).

**Example**:
```c
char* version = airgap_get_version();
printf("AirGapSync version: %s\n", version);
airgap_free_string(version);
```

### Configuration

#### airgap_load_config

Load configuration from a TOML file.

```c
Config* airgap_load_config(const char* config_path);
```

**Parameters**:
- `config_path`: Path to TOML config file (UTF-8, null-terminated)

**Returns**: Config pointer, or NULL on error.

**Example**:
```c
Config* config = airgap_load_config("/path/to/config.toml");
if (config == NULL) {
    fprintf(stderr, "Failed to load config\n");
    exit(1);
}
```

#### airgap_free_config

Free a configuration object.

```c
void airgap_free_config(Config* config);
```

**Parameters**:
- `config`: Config pointer to free

**Example**:
```c
airgap_free_config(config);
```

### Engine Management

#### airgap_create_engine

Create a sync engine from configuration.

```c
SyncEngineHandle* airgap_create_engine(const Config* config);
```

**Parameters**:
- `config`: Valid configuration pointer

**Returns**: Engine handle, or NULL on error.

**Example**:
```c
SyncEngineHandle* engine = airgap_create_engine(config);
if (engine == NULL) {
    fprintf(stderr, "Failed to create engine\n");
    exit(1);
}
```

#### airgap_free_engine

Free a sync engine.

```c
void airgap_free_engine(SyncEngineHandle* engine);
```

**Parameters**:
- `engine`: Engine handle to free

**Example**:
```c
airgap_free_engine(engine);
```

### Sync Operations

#### airgap_sync

Perform a sync operation.

```c
FFIResult airgap_sync(
    SyncEngineHandle* engine,
    const char* device_id,
    const FFISyncOptions* options,
    FFIProgressCallback callback,      // Optional: can be NULL
    void* callback_context,            // Optional: passed to callback
    FFISyncResult* result             // Output: sync results
);
```

**Parameters**:
- `engine`: Valid engine handle
- `device_id`: Device ID string (UTF-8, null-terminated)
- `options`: Sync options
- `callback`: Progress callback (currently not implemented, pass NULL)
- `callback_context`: Context for callback (pass NULL)
- `result`: Output parameter for sync results

**Returns**: FFIResult indicating success or error.

**Example**:
```c
FFISyncOptions options = {
    .dry_run = false,
    .verbose = false,
    .parallel_workers = 4,
    .chunk_size = 1024 * 1024,  // 1 MB
    .verify_after_write = true,
    .resume = true,
    .compression_level = 6,
    .show_progress = true,
    .max_retries = 3
};

FFISyncResult sync_result = {0};

FFIResult result = airgap_sync(
    engine,
    "DEVICE_001",
    &options,
    NULL,  // No callback
    NULL,  // No context
    &sync_result
);

if (result.error_code == Success) {
    printf("Synced %llu files\n", sync_result.files_synced);
    printf("Transferred %llu bytes\n", sync_result.bytes_transferred);

    if (sync_result.snapshot_id != NULL) {
        printf("Snapshot: %s\n", sync_result.snapshot_id);
        airgap_free_string(sync_result.snapshot_id);
    }
} else {
    fprintf(stderr, "Sync failed: %s\n", result.error_message);
    airgap_free_string(result.error_message);
}
```

### Snapshot Operations

#### airgap_list_snapshots

List snapshots for a device.

```c
char** airgap_list_snapshots(
    const Config* config,
    const char* device_id,
    uint32_t* out_count         // Output: number of snapshots
);
```

**Parameters**:
- `config`: Valid configuration
- `device_id`: Device ID string
- `out_count`: Output parameter for snapshot count

**Returns**: Array of snapshot ID strings, or NULL if none.

**Example**:
```c
uint32_t count = 0;
char** snapshots = airgap_list_snapshots(config, "DEVICE_001", &count);

if (snapshots != NULL) {
    for (uint32_t i = 0; i < count; i++) {
        printf("Snapshot %u: %s\n", i, snapshots[i]);
    }

    airgap_free_snapshot_list(snapshots, count);
}
```

Free a list of snapshots.

```c
void airgap_free_snapshot_list(char** snapshots, uint32_t count);
```

Verify snapshot integrity.

FFIResult airgap_verify_snapshot(

**Returns**: FFIResult indicating success or verification failure.

#### airgap_get_snapshot_info

char* airgap_get_snapshot_info(

**Returns**: Human-readable snapshot info string (must be freed).

### Memory Management

#### airgap_free_string

Free a string allocated by the library.

```c
void airgap_free_string(char* s);
```

**Parameters**:
- `s`: String pointer to free

**Example**:
```c
char* version = airgap_get_version();
// Use version...
airgap_free_string(version);
```

#### airgap_free_sync_result

Free a sync result structure.

```c
void airgap_free_sync_result(FFISyncResult* result);
```

**Note**: Only frees the `snapshot_id` field. The structure itself is typically stack-allocated.

#### airgap_free_result

Free an FFIResult error message.

```c
void airgap_free_result(FFIResult* result);
```

**Note**: Only frees the `error_message` field.

## Memory Management

### Rules

1. **Strings**: All strings returned by FFI functions must be freed with `airgap_free_string()`.

2. **Structures**: Structures with allocated fields must be freed with their specific free function.

3. **Opaque Pointers**: Must be freed with their specific free function (e.g., `airgap_free_config()`).

4. **Stack Allocation**: Input structures (like `FFISyncOptions`) can be stack-allocated.

### Example: Complete Lifecycle

```c
// Initialize
FFIResult init_result = airgap_initialize();
assert(init_result.error_code == Success);

// Load config
Config* config = airgap_load_config("/path/to/config.toml");
assert(config != NULL);

// Create engine
SyncEngineHandle* engine = airgap_create_engine(config);
assert(engine != NULL);

// Perform sync
FFISyncOptions options = {
    .dry_run = false,
    .parallel_workers = 4,
    .chunk_size = 1024 * 1024,
    .verify_after_write = true,
    .resume = true,
    .compression_level = 6,
    .show_progress = true,
    .max_retries = 3
};

FFISyncResult sync_result = {0};
FFIResult result = airgap_sync(
    engine,
    "DEVICE_001",
    &options,
    NULL,
    NULL,
    &sync_result
);

if (result.error_code == Success) {
    printf("Synced %llu files\n", sync_result.files_synced);

    if (sync_result.snapshot_id != NULL) {
        printf("Snapshot: %s\n", sync_result.snapshot_id);
        airgap_free_string(sync_result.snapshot_id);
    }
} else {
    fprintf(stderr, "Error: %s\n", result.error_message);
    airgap_free_string(result.error_message);
}

// Clean up
airgap_free_engine(engine);
airgap_free_config(config);
```

## Error Handling

### Pattern

Always check return values:

```c
FFIResult result = some_function();
if (result.error_code != Success) {
    // Handle error
    if (result.error_message != NULL) {
        fprintf(stderr, "Error: %s\n", result.error_message);
        airgap_free_string(result.error_message);
    }
    return;
}
```

### Error Codes

| Code | Meaning | Common Cause |
|------|---------|--------------|
| Success | Operation succeeded | - |
| NullPointer | NULL pointer argument | Forgot to initialize something |
| InvalidUtf8 | String is not valid UTF-8 | Incorrect string encoding |
| ConfigError | Configuration problem | Invalid config file |
| CryptoError | Cryptography error | Wrong key, corrupted data |
| KeychainError | Keychain access failed | Permission denied |
| IoError | File I/O error | File not found, permission denied |
| DeviceNotFound | Device doesn't exist | Wrong device ID |
| SyncError | Sync operation failed | Various causes (check message) |
| Unknown | Unknown error | Report as bug |

## Threading

### Thread Safety

- **Initialization**: `airgap_initialize()` is thread-safe and idempotent.
- **Read Operations**: Multiple threads can read from the same config/engine.
- **Write Operations**: Syncs should not run concurrently on the same engine.
- **Multiple Engines**: Each thread can have its own engine safely.

### Example: Concurrent Access

```c
// Safe: Multiple threads can call this
void* thread_func(void* arg) {
    char* version = airgap_get_version();
    printf("Version: %s\n", version);
    airgap_free_string(version);
    return NULL;
}

// Safe: Each thread has its own engine
void* sync_thread(void* arg) {
    Config* config = airgap_load_config("/path/to/config.toml");
    SyncEngineHandle* engine = airgap_create_engine(config);

    // ... perform sync ...

    airgap_free_engine(engine);
    airgap_free_config(config);
    return NULL;
}

// UNSAFE: Don't do this
void* unsafe_thread(void* shared_engine) {
    // Multiple threads syncing with same engine
    // This will cause data races!
    FFIResult result = airgap_sync(shared_engine, ...);
}
```

## Examples

### Swift Example

```swift
import Foundation

class AirGapSyncManager {
    private var config: OpaquePointer?
    private var engine: OpaquePointer?

    init(configPath: String) throws {
        // Initialize library
        let initResult = airgap_initialize()
        guard initResult.error_code == Success else {
            throw AirGapError(from: initResult)
        }

        // Load config
        config = configPath.withCString { path in
            airgap_load_config(path)
        }

        guard config != nil else {
            throw AirGapError.configError("Failed to load config")
        }

        // Create engine
        engine = airgap_create_engine(config)
        guard engine != nil else {
            throw AirGapError.engineError("Failed to create engine")
        }
    }

    deinit {
        if let engine = engine {
            airgap_free_engine(engine)
        }
        if let config = config {
            airgap_free_config(config)
        }
    }

    func sync(deviceId: String) throws -> SyncResult {
        guard let engine = engine else {
            throw AirGapError.engineError("Engine not initialized")
        }

        var options = FFISyncOptions(
            dry_run: false,
            verbose: false,
            parallel_workers: 4,
            chunk_size: 1024 * 1024,
            verify_after_write: true,
            resume: true,
            compression_level: 6,
            show_progress: true,
            max_retries: 3
        )

        var syncResult = FFISyncResult()

        let result = deviceId.withCString { deviceIdPtr in
            airgap_sync(
                engine,
                deviceIdPtr,
                &options,
                nil,
                nil,
                &syncResult
            )
        }

        guard result.error_code == Success else {
            throw AirGapError(from: result)
        }

        return SyncResult(from: syncResult)
    }
}
```

### Objective-C Example

```objective-c
#import "airgapsync.h"

@interface AirGapSyncManager : NSObject
- (instancetype)initWithConfigPath:(NSString *)configPath error:(NSError **)error;
- (BOOL)syncToDevice:(NSString *)deviceId error:(NSError **)error;
@end

@implementation AirGapSyncManager {
    Config *_config;
    SyncEngineHandle *_engine;
}

- (instancetype)initWithConfigPath:(NSString *)configPath error:(NSError **)error {
    self = [super init];
    if (self) {
        // Initialize
        FFIResult initResult = airgap_initialize();
        if (initResult.error_code != Success) {
            if (error) *error = [self errorFromFFIResult:initResult];
            return nil;
        }

        // Load config
        _config = airgap_load_config([configPath UTF8String]);
        if (_config == NULL) {
            if (error) *error = [NSError errorWithDomain:@"AirGapSync"
                                                   code:-1
                                               userInfo:@{@"message": @"Failed to load config"}];
            return nil;
        }

        // Create engine
        _engine = airgap_create_engine(_config);
        if (_engine == NULL) {
            airgap_free_config(_config);
            if (error) *error = [NSError errorWithDomain:@"AirGapSync"
                                                   code:-2
                                               userInfo:@{@"message": @"Failed to create engine"}];
            return nil;
        }
    }
    return self;
}

- (void)dealloc {
    if (_engine) airgap_free_engine(_engine);
    if (_config) airgap_free_config(_config);
}

- (BOOL)syncToDevice:(NSString *)deviceId error:(NSError **)error {
    FFISyncOptions options = {
        .dry_run = false,
        .verbose = false,
        .parallel_workers = 4,
        .chunk_size = 1024 * 1024,
        .verify_after_write = true,
        .resume = true,
        .compression_level = 6,
        .show_progress = true,
        .max_retries = 3
    };

    FFISyncResult syncResult = {0};

    FFIResult result = airgap_sync(
        _engine,
        [deviceId UTF8String],
        &options,
        NULL,
        NULL,
        &syncResult
    );

    if (result.error_code != Success) {
        if (error) *error = [self errorFromFFIResult:result];
        if (result.error_message) airgap_free_string(result.error_message);
        return NO;
    }

    NSLog(@"Synced %llu files", syncResult.files_synced);

    if (syncResult.snapshot_id) {
        NSLog(@"Snapshot: %s", syncResult.snapshot_id);
        airgap_free_string(syncResult.snapshot_id);
    }

    return YES;
}

- (NSError *)errorFromFFIResult:(FFIResult)result {
    NSString *message = @"Unknown error";
    if (result.error_message) {
        message = [NSString stringWithUTF8String:result.error_message];
    }
    return [NSError errorWithDomain:@"AirGapSync"
                               code:result.error_code
                           userInfo:@{@"message": message}];
}

@end
```

## Best Practices

1. **Always Check Returns**: Never ignore error codes or NULL returns.

2. **Free Resources**: Use RAII patterns or explicit cleanup to ensure resources are freed.

3. **Defensive Coding**: Validate inputs before passing to FFI functions.

4. **Error Messages**: Always read and free error messages for debugging.

5. **UTF-8 Encoding**: Ensure all strings are valid UTF-8.

6. **Thread Safety**: Don't share engines between threads without synchronization.

7. **Initialization**: Call `airgap_initialize()` exactly once at startup.

## Troubleshooting

### Linker Errors

```
Undefined symbols for architecture x86_64:
  "_airgap_initialize"
```

**Solution**: Add `-L/path/to/lib -lairgap_sync` to linker flags.

### Runtime Crashes

```
dyld: Library not loaded: @rpath/libairgap_sync.dylib
```

**Solution**:
- Use static library (.a) instead of dynamic (.dylib), OR
- Add library path to DYLD_LIBRARY_PATH

### Header Not Found

```
fatal error: 'airgapsync.h' file not found
```

**Solution**: Add `-I/path/to/headers` to compiler flags.
