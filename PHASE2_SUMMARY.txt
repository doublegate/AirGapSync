KEY FEATURES IMPLEMENTED

SYNC ENGINE
-----------
• Full directory synchronization
• Incremental sync (only changed files)
• Change detection (new/modified/deleted)

STORAGE
-------
• Chunk-based processing (1MB default, configurable)
• Content-addressed deduplication (SHA-256)
• Optional compression (gzip/deflate)
• Encryption (AES-256-GCM, ChaCha20-Poly1305)
• Reference counting for chunks
• Streaming for large files

ARCHIVE

• Multiple snapshots per device
• Snapshot verification
• Archive statistics
• Index for fast lookups
• Organized directory structure

RESTORE
-------
• Full snapshot restore
• Chunk reassembly
• Automatic decryption/decompression
• Progress tracking
• File integrity verification

CLI COMMANDS
============

New commands added:

  airgapsync sync              - Sync files to removable media
    --source <path>              Source directory
    --dest <path>                Destination device path
    --device-id <id>             Device ID for encryption
    --dry-run                    Preview changes only
    --chunk-size <kb>            Chunk size (default: 1024)
    --no-compress                Disable compression
    --no-encrypt                 Disable encryption

  airgapsync verify            - Verify backup integrity
    --archive <path>             Archive path
    --device-id <id>             Device ID
    --snapshot <id>              Snapshot ID (latest if omitted)

  airgapsync list-snapshots    - List available snapshots
    --archive <path>             Archive path
    --device-id <id>             Device ID

  airgapsync restore           - Restore from backup
    --archive <path>             Archive path
    --device-id <id>             Device ID
    --snapshot <id>              Snapshot ID
    --dest <path>                Restore destination

  airgapsync stats             - Show archive statistics
    --archive <path>             Archive path
    --device-id <id>             Device ID

ARCHIVE FORMAT
==============

Directory structure on removable media:

/Volumes/USB001/
  .airgapsync/
    device-<id>/
      snapshots/
        <snapshot-id>/
          manifest.json          # File and chunk metadata
          chunks/                # Encrypted chunks
            ab/
              ab123456...        # Chunk files (SHA-256 hash)
            cd/
              cd789abc...
      current -> snapshots/latest  # Symlink to latest
    index.json                   # Snapshot index
    version                      # Archive format version

USAGE EXAMPLE
=============

    --source ~/Documents \
